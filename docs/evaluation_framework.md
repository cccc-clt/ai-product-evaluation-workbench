# 评测框架

## 1. 模型评测维度

| 维度 | 说明 | 度量方式 |
|------|------|----------|
| **准确性** | 回答是否正确、完整 | 人工评分 1-5 |
| **响应速度** | 首 token 到完整响应的时间 | 系统记录 latency_ms |
| **成本效率** | 单位请求的 Token 与费用 | input/output tokens + 估算 USD |
| **稳定性** | 多次调用是否一致 | MVP：单次记录；后续：批量方差 |
| **格式遵循** | 是否按 Prompt 要求输出 | 人工备注 + RAG 标签 |

### 模型评分规则（人工）

| 分数 | 含义 |
|------|------|
| 5 | 完全满足需求，可直接上线 |
| 4 | 基本满足， minor 修改即可 |
| 3 | 部分满足，需明显改进 |
| 2 | 多数不满足，需重做 |
| 1 | 完全不可用 |

## 2. Prompt 评测维度

| 维度 | 说明 | 记录方式 |
|------|------|----------|
| **场景适配** | Prompt 是否匹配业务场景 | 场景字段 + 实验次数 |
| **指令清晰度** | System Prompt 是否明确角色与约束 | 人工备注 |
| **输出可控性** | temperature / max_tokens 是否合理 | 参数记录 |
| **版本迭代** | 不同版本效果对比 | version 字段 |

### Prompt 实验记录字段

- scene, system_prompt, user_prompt, model, temperature, max_tokens
- response, latency_ms, tokens, cost, version, created_at

## 3. RAG 评测维度

| 维度 | 说明 | 度量方式 |
|------|------|----------|
| **检索相关性** | 召回片段是否与问题相关 | 引用片段展示 + 相关度 score |
| **回答 grounded 度** | 回答是否基于引用片段 | 人工判断 + 「幻觉」标签 |
| **引用准确性** | 引用内容是否来自正确片段 | 「引用错误」标签 |
| **完整性** | 是否遗漏关键信息 | 「回答太泛」「答案太短」标签 |
| **格式与理解** | 格式、题意理解 | 「没有按照格式输出」「理解错问题」 |

### RAG 流程评测点

1. **文档解析**：PDF/TXT 是否成功提取文本
2. **分块质量**：chunk_size/overlap 是否合理（默认 500/50）
3. **检索 Top-K**：默认 top_k=3，是否覆盖关键信息
4. **生成质量**：基于引用的回答是否忠实

## 4. 反馈标签体系

### RAG 问题标签（8 类）

| 标签 | 定义 | 典型触发 |
|------|------|----------|
| 幻觉 | 回答包含文档未提及的信息 | 编造数据、虚构政策 |
| 引用错误 | 引用片段与回答不对应 | 张冠李戴 |
| 回答太泛 | 缺乏具体细节 | 空洞总结 |
| 没有按照格式输出 | 未遵循 Prompt 格式要求 | 缺列表/表格 |
| 理解错问题 | 答非所问 | 误解用户意图 |
| 答案太短 | 信息不足 | 一句话敷衍 |
| 速度太慢 | 响应时间过长 | latency 超阈值 |
| 成本太高 | Token/费用超出预期 | 长回答高成本 |

### 标签使用规则

- 可多选
- 保存至 `rag_evaluations.tags`（JSON 数组）
- 看板聚合为「高频失败原因」

## 5. 评分规则汇总

### 低分样本定义

- 人工评分 < 3（Prompt 实验、多模型对比、RAG 评测）
- 用于 AI 优化建议模块的输入

### 看板聚合指标

| 指标 | 计算方式 |
|------|----------|
| 平均评分 | 所有有人工/用户评分的记录均值 |
| 模型平均得分 | 按 model 分组 AVG(human_score) |
| 场景测试次数 | 按 scene 分组 COUNT |
| 标签分布 | 按 tag 计数 |
| Prompt 版本数 | COUNT(DISTINCT version) |

### 成本估算规则（简化）

| 模型 | Input ($/1K) | Output ($/1K) |
|------|--------------|---------------|
| gpt-4o-mini | 0.00015 | 0.0006 |
| gpt-4o | 0.0025 | 0.01 |
| 其他 | 0.001 | 0.002（默认） |

> 成本为估算值，实际以 API 账单为准。

## 6. AI 优化建议输入

优化建议模块读取：

1. 低分样本（score < 3）的内容摘要
2. 各模型平均得分
3. 场景测试次数分布
4. RAG 问题标签 Top N

输出五类结构化建议：Prompt / 模型 / 参数 / RAG / 产品体验。

## 7. 评测流程建议

```
1. 定义场景与测试集（5-10 条代表性问题）
2. Prompt 实验台迭代 System Prompt，保存 v1/v2/v3
3. 多模型对比选出 1-2 个候选模型
4. RAG 场景上传文档，针对易错问题评测并打标签
5. 看板复盘，AI 优化建议生成下周行动项
6. 循环直至平均评分 ≥ 4 且高频标签下降
```
